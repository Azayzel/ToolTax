# Shelved

## Automatic tool removal
ToolTax should recommend; it should not silently change MCP configuration. Removal is too consequential for a heuristic score.

## Dollar-cost claims from local transcripts
Shelved until provider/model pricing and exact billable token attribution can be grounded reliably.

## LLM-based semantic usefulness scoring in core
Tempting, but it makes ToolTax slower, more expensive, less reproducible, and ironically adds another model/tool tax. Keep core deterministic.

## Central hosted trace ingestion
Potential product direction, but conflicts with the privacy-first viral OSS story. Revisit only with explicit redaction and opt-in architecture.
